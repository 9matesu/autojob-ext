# resuMe v1.0.0 — Release Plan

Repo: `I:\autojob\autojob-ext` (git branch: work on `main`, commit per task).
Shell used throughout: git-bash (POSIX). All `npm`/`pytest` commands run from the directory stated.

## Goal

Rename AutoJob Studio → **resuMe**, ship a 1.0.0 Chrome extension + a downloadable
portable zip (extension + local FastAPI/Tectonic backend, fully offline), with a
typography system of **only Instrument Serif + Switzer** (bundled locally, no
Google Fonts CDN), a **single-Esc** div chooser whose captured text is editable
before capture, a "Me" modernist logo, and full documentation.

## Current context (verified by inspection)

- Structure: `extension/` (MV3: manifest.json, background.js, content.js + built pages),
  `ui/` (React 19 + Vite 8 + Tailwind 4, builds into `extension/`), `backend/`
  (FastAPI, port 8322, SQLite, Tectonic LaTeX, 11 AI providers via
  `backend/app/services/ai/gateway.py`), `native-host/` (`AutoJobHost.exe` source
  `host_main.py`, registers `com.autojob.host`).
- Name "AutoJob" is hardcoded in ~23 files: manifest, message types
  (`autojob-capture-start` / `autojob-capture-result`), DOM attribute
  `data-autojob`, native host name, env var `AUTOJOB_DATA_DIR`, UI strings.
- Fonts today: body = **Space Mono** (remote Google Fonts `<link>` in
  `ui/sidepanel.html` + `ui/studio.html`), `.font-editorial` = Instrument Serif
  (also remote). Switzer not present. content.js toast/hint use `"Space Mono"`
  in inline `cssText`.
- Div chooser (`extension/content.js`): inspector mode with overlay; click →
  "confirm" mode → yellow preview toast with `<pre>` (read-only, 600 chars).
  **The double-Esc pain**: in confirm mode Esc calls `backToSelection()` (line 233),
  a second Esc calls `cancel()`. Desired: one Esc exits inspector entirely.
- Backend tests exist: `backend/tests/` (pytest, 3 files). UI has `oxlint` + `tsc`
  as gates; no JS test runner — UI verification is build+lint+manual checklist.
- `extension/manifest.json` has a fixed `key` → extension ID survives the rename.
  No icons in the manifest yet.
- Packaging: no release script exists; `backend/bin/` is empty (Tectonic expected
  there or on PATH — `latex_engine.find_compiler()`).

## Assumptions

- UI language stays PT-BR (current strings are PT-BR).
- The portable zip targets Windows only (native host, MiKTeX/Tectonic, PowerShell
  scripts already are).
- Switzer license (SIL OFL via Fontshare) and Instrument Serif (OFL) allow
  redistribution inside the zip — both do; include their license files.
- API keys stay local-sidecar-only (server-side, never in extension code) — this
  is existing behavior; preserve it.

## Architecture / approach

Rename is a mechanical, verifiable string sweep across four coordinated layers
(extension messages ↔ content script ↔ UI ↔ native host must stay in sync in the
same commits). Typography becomes two locally-bundled woff2 families via
`@font-face` in `ui/src/index.css` and inline styles in `content.js`. The chooser
becomes a two-state overlay (select → editable preview) where Esc from **any**
state terminates the session, and the preview `<pre>` becomes a `<textarea>` whose
edited text is what gets POSTed. Release packaging is one PowerShell script that
stages extension + embedded CPython + backend + Tectonic into
`dist/resuMe-1.0.0-windows-x64.zip`.

## Phase E — Website download + portable backend (the 1.0 artifact)

### Task E1: Release packaging script

Create `scripts/package-release.ps1` (repo root). It builds a self-contained
Windows zip: extension + backend with an **embedded CPython** + Tectonic +
native host + docs. Full content:

```powershell
# scripts/package-release.ps1 — builds dist/resuMe-<ver>-windows-x64.zip
$ErrorActionPreference = "Stop"
$root = Split-Path -Parent $PSScriptRoot
$ver = (Get-Content "$root\extension\manifest.json" -Raw | ConvertFrom-Json).version
$stage = "$root\dist\resuMe-$ver"
$pyVer = "3.12.7"; $pyTag = "20241006"   # python-build-standalone release (verify at build time against https://github.com/astral-sh/python-build-standalone/releases/latest)
$st = "x86_64-pc-windows-msvc"

Remove-Item $stage -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path $stage | Out-Null

# 1. Extension (load-unpacked folder, ready for chrome://extensions)
Copy-Item "$root\extension" "$stage\extension" -Recurse
Copy-Item "$root\README.md","$root\CHANGELOG.md" $stage -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path "$stage\docs" | Out-Null
Copy-Item "$root\docs\*" "$stage\docs"

# 2. Embedded Python (no installer, no PATH pollution)
$pyZip = "$env:TEMP\python-standalone.zip"
Invoke-WebRequest "https://github.com/astral-sh/python-build-standalone/releases/download/$pyTag/cpython-$pyVer+$pyTag-$st-install_only.tar.gz" -OutFile $pyTar
# (PowerShell: use .tar.gz via tar.exe which ships with Win10+)
tar -xzf $pyTar -C $stage
Rename-Item "$stage\python" "python-embedded"
& "$stage\python-embedded\python.exe" -m pip install -r "$root\backend\requirements.txt"

# 3. Backend sources
Copy-Item "$root\backend" "$stage\backend" -Recurse
Remove-Item "$stage\backend\tests","$stage\backend\data","$stage\backend\__pycache__" -Recurse -Force -ErrorAction SilentlyContinue
Get-ChildItem "$stage\backend" -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force

# 4. Tectonic single binary
$tect = "https://github.com/tectonic-typesetting/tectonic/releases/download/tectonic%400.15.0/tectonic-0.15.0-x86_64-pc-windows-msvc.zip"
Invoke-WebRequest $tect -OutFile "$env:TEMP\tectonic.zip"
Expand-Archive "$env:TEMP\tectonic.zip" -DestinationPath "$stage\backend\bin"

# 5. Native host (rebuild exe against renamed host from Task A3 if you rebuilt; else ship sources)
Copy-Item "$root\native-host" "$stage\native-host" -Recurse

# 6. One-click launcher
@'
$ErrorActionPreference = "Stop"
$root = Split-Path -Parent $MyInvocation.MyCommand.Path
& "$root\python-embedded\python.exe" -m uvicorn app.main:app --host 127.0.0.1 --port 8322 --app-dir "$root\backend"
'@ | Set-Content "$stage\start-engine.ps1"
@'
```

## Risks / tradeoffs

- **Partial rename = silent breakage**: message-type or host-name mismatch between
  extension and native host fails only at runtime. Mitigated by A2's one-commit
  sweep + A3 smoke. Re-registering the native host on existing installs requires
  re-running `install-host.ps1` — document in CHANGELOG (breaking for 0.x users).
- **Fontshare/CSS scraping** in B1 depends on UA header for woff2; if the CDN
  returns ttf, convert with `fonttools` (`pip install fonttools; pyftsubset`) —
  same license path.
- **Embedded CPython zip size** (~60–80 MB with deps). Accepted for "portable"
  promise; the alternative (require Python install) contradicts the brief.
- **`state.pending` getter** in C3 is fine in content-script ES context; if any
  Chrome 114 edge misbehaves, replace with a plain update on `ta` `input` event
  (`ta.addEventListener('input', () => { state.pending.text = ta.value })`).
- **Extension store** out of scope (load-unpacked + zip per brief); store listing
  later if desired.
- `ui/package-lock.json` keeps `autojob-ext-ui` name until an `npm install`
  regenerates it — acceptable, or run `npm install` in A2 to sync.
