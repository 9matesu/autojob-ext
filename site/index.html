Como funciona

Instale em 2 minutos

Baixe o zip, descompacte onde quiser e arraste a pasta extension para dentro do Chrome. Não tem instalador, não pede direitos de administrador, não mexe no seu Python. O guia ilustrado mostra cada clique.

Envie seu currículo uma única vez

PDF, Word, texto ou LaTeX — o resuMe monta seu perfil mestre e você revisa seção por seção antes de confirmar. Ele é a única fonte de fatos: o que não estiver nele, a IA não escreve.

Navegue e capture

Viu uma vaga no LinkedIn, Gupy ou Indeed? Aperte Alt+Shift+A, clique no texto da vaga, ajuste a prévia se quiser e baixe o PDF adaptado. Um Esc cancela tudo a qualquer momento.

Perguntas que todo mundo faz

É grátis de verdade?

Sim. O resuMe é gratuito e tem código aberto — você pode ler, auditar e modificar tudo. O único custo possível é a API de IA que você escolher usar (ou zero, com Ollama local).

Preciso criar conta ou colocar cartão?

Nenhum dos dois. Baixa o zip, carrega a pasta no Chrome e usa.

Meus dados vão para algum servidor?

O texto da vaga e o seu perfil vão apenas para o provedor de IA que você configurar. Sem chave configurada, o app se recusa a inventar conteúdo — ele nunca fabrica currículo. Não há telemetria nem analytics.

Funciona no macOS ou Linux?

Por enquanto, Windows 10/11. Suporte para outros sistemas está nos planos — o motor é Python, então o caminho está aberto.

O Windows avisou que o arquivo não é confiável. É seguro?

O aviso do SmartScreen aparece porque software sem certificado pago sempre dispara ele — não é vírus. Está explicado passo a passo no guia de instalação, e o código é aberto para auditoria.

A IA pode inventar experiência no meu currículo?

As regras do prompt proíbem: ela só reorganiza e reescreve os fatos do seu perfil mestre com a ênfase da vaga. E você revisa cada linha antes de enviar — no Estúdio, com edição visual e do LaTeX.
